# Security policy

`bash-http-lab` is an educational experiment, not a production HTTP server. It
must not be exposed to the internet or used to protect sensitive data.

Please report vulnerabilities privately through this repository's GitHub
Security Advisories. Include the affected revision, a minimal reproduction, and
the impact you observed. Do not include real credentials or personal data.

General hardening ideas and non-sensitive defects can be reported through the
public issue tracker.
